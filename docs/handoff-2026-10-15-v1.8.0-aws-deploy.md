## 4. Chi tiết thay đổi code

### 4.1 Deploy-ready source (`378315f`)
- `config.json` **không còn** `auth-key` (repo `ken-online/chatgpt2api` là **PUBLIC**).
- `docker-compose.yml`: `CHATGPT2API_AUTH_KEY: ${CHATGPT2API_AUTH_KEY:?…}` — thiếu `.env` thì compose dừng với thông báo rõ. Đã test clone sạch trên VPS (không `.env` → lỗi rõ; có `.env` → OK).
- Thứ tự đọc key: `os.getenv("CHATGPT2API_AUTH_KEY") or config["auth-key"]` (`services/config.py` `_load_settings`).
- Chạy test/import local phải `export CHATGPT2API_AUTH_KEY=test-local-key`.

### 4.2 Trang Image
- **Layout** (`web/src/app/image/page.tsx`): bỏ `max-w-[1380px] mx-auto`; cột phải là `div.flex-col.gap-3` chứa `Card` kết quả (`flex-1`) + `ImageComposer` riêng bên dưới.
- **Sửa prompt** (`components/image-results.tsx`): nút ✏️ *Sửa* → textarea tại chỗ, *Lưu & tạo lại* / Ctrl+Enter, Esc huỷ. Gọi `onRegenerateTurn(convId, turnId, newPrompt)` → `handleRegenerateTurn` ghi `prompt` mới vào turn rồi chạy luồng tạo lại có sẵn (ảnh cũ vào `revisions`, xem bằng ◀ ▶). Queue đọc `activeTurn.prompt` đã persist nên prompt mới chắc chắn được dùng.
- **Ngữ cảnh lượt tiếp theo** (`83fb433`): backend **stateless** — mỗi lượt là 1 request độc lập (`createImageGenerationTask` chỉ gửi prompt; config `image_remove_conversation_after_result: true` còn ẩn hội thoại ChatGPT sau mỗi lượt). Giải pháp Ken chọn: helper `buildPreviousResultReference()` lấy ảnh `success` gần nhất của các lượt trước làm tham chiếu khi lượt mới **không** có ảnh đính kèm → mode `edit`. Áp dụng ở `handleSubmit` và `handleRegenerateTurn` (khi có `newPrompt`). Đọc ảnh lỗi → toast + **dừng** (không gửi thiếu ngữ cảnh).
  - Phương án bị loại: nối hội thoại thật trên ChatGPT (cần giữ conversation_id + tắt remove-conversation + cố định account — thay đổi backend lớn).

### 4.3 Accounts

### 4.4 i18n (`f85be7d`)
- **Gốc** tiếng Trung từ ChatGPT: backend gửi `OAI-Language: zh-CN` + `Accept-Language: zh-CN` (`services/openai_backend_api.py` ~dòng 193, 211, 383) → đổi `vi-VN`. `timezone`/`timezone_offset_min` vẫn `Asia/Shanghai`/-480 (chưa đổi, không ảnh hưởng hiển thị).

## 6. Bài học / bẫy gặp trong phiên
1. **Line ending**: `sed -i` (Git Bash) và script Python ghi file đã đổi LF↔CRLF ở vài file → diff phình cả file. Repo **lẫn lộn** LF/CRLF theo từng file (vd `web/src/app/page.tsx` CRLF, đa số LF). Sau khi sửa hàng loạt: so `git show HEAD:<f>` đếm `\r\n` và trả về đúng. `git diff --stat` phải khớp số dòng thực sửa.
2. `grep -c $'\r$'` qua rtk/Git Bash cho số **sai** — dùng Python đếm bytes.
3. Classifier Claude Code chặn tự bấm "Create database" (giao dịch tốn tiền) → Ken bấm tay. Xoá tài nguyên thì làm được khi Ken cho phép rõ.
4. Không nhập key vào web app trên domain thật qua browser automation → không tự xem UI sau đăng nhập; verify bằng grep bundle trong container + Ken xem.
