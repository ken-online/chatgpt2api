### 4.5 Bug phát hiện khi e2e nút Sửa (`efb377a`, `d2f53df`)
- **"Failed to fetch" khi lấy ảnh lượt trước**: sau Cloudflare Tunnel, uvicorn không tin `X-Forwarded-Proto` (peer là docker bridge, không phải 127.0.0.1) → `resolve_image_base_url` (`api/support.py`) sinh URL `http://`. `<img>` được Chrome tự nâng https nên vẫn hiện, nhưng `fetch()` bị chặn mixed content.
  - Fix gốc: `Dockerfile` CMD thêm `--forwarded-allow-ips "*"` (an toàn: app không dùng IP client ở đâu). Ảnh mới giờ là `https://`.
  - Dữ liệu cũ (URL `http://` lưu trong IndexedDB trình duyệt): `fetchImageAsFile` (`web/src/app/image/page.tsx`) — URL cùng host thì dùng protocol của trang. Hàm dùng chung nên sửa luôn cho Dùng lại / Tạo lại.
  - Phương án thay thế không chọn: đặt `CHATGPT2API_BASE_URL` trong `.env` VPS (chỉ sửa 1 máy, không deploy-ready).
- **Tạo lại xong ảnh không hiện**: `handleRegenerateTurn` giữ `resultsDeleted: true` của turn cũ → ảnh tạo xong (tốn quota) nhưng bị ẩn. Fix: reset `resultsDeleted: false` khi tạo lại (ảnh hưởng cả nút Tạo lại).
- E2E đã pass trên Chrome của Ken: Lần 2 → "Chỉnh sửa" + tham chiếu bộ icon Lần 1 → ra ảnh mới, PNG nền trong suốt thật (49% pixel alpha = 0).

## 6. Bài học / bẫy gặp trong phiên
1. **Line ending**: `sed -i` (Git Bash) và script Python ghi file đã đổi LF↔CRLF ở vài file → diff phình cả file. Repo **lẫn lộn** LF/CRLF theo từng file (vd `web/src/app/page.tsx` CRLF, đa số LF). Sau khi sửa hàng loạt: so `git show HEAD:<f>` đếm `\r\n` và trả về đúng. `git diff --stat` phải khớp số dòng thực sửa.
2. `grep -c $'\r$'` qua rtk/Git Bash cho số **sai** — dùng Python đếm bytes.
3. Classifier Claude Code chặn tự bấm "Create database" (giao dịch tốn tiền) → Ken bấm tay. Xoá tài nguyên thì làm được khi Ken cho phép rõ.
4. Không nhập key vào web app trên domain thật qua browser automation. **Cập nhật**: Chrome của Ken (deviceId `0724406c…`) đã có phiên đăng nhập sẵn `gpt.zway.ninja` → e2e trực tiếp được, không cần nhập key.
5. Bug chỉ lộ khi chạy **sau proxy HTTPS thật** (mixed content) — test local http không bắt được. Sau mỗi thay đổi luồng ảnh nên e2e trên `gpt.zway.ninja`.
6. Script ánh xạ class màu hàng loạt: chỉ sửa dòng không có `dark:` và **rà lại mọi chỗ thành `primary-*`** — `bg-stone-950` có thể là khối code tối chứ không phải nút (đã bắt được 1 chỗ trong API docs).
7. `npx tsc` có lúc báo thiếu typescript → chạy `node node_modules/typescript/bin/tsc --noEmit -p .` trong `web/`.
